## Repository map

- apps/backend: Bun and Elysia API using the Zaatot modular conventions.
- apps/desktop: Tauri and React desktop client.
- apps/mobile: React Native mobile client.
- apps/portal: Internal download and administration portal.
- services/ai: Python audio, transcription, and translation worker.
- packages/contracts: Shared API and real-time event contracts.
- infra/compose: Local and single-server deployment.
- infra/helm: Enterprise Kubernetes deployment.
- infra/offline: Air-gapped image and model packaging.
- docs: Architecture decisions, deployment guides, and hardware guidance.
